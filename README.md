# Corporate-Bankruptcy-Forecaster
AI-powered corporate bankruptcy prediction dashboard using Random Forest and financial ratios to assess a company's financial distress and bankruptcy risk.

Corporate Bankruptcy Forecaster is an AI-powered financial analytics dashboard that predicts the bankruptcy risk of companies using machine learning. The project uses the Polish Companies Bankruptcy Dataset and a Random Forest classification model trained on 64 financial ratios. It includes data preprocessing, missing-value handling, SMOTE for class imbalance, threshold optimization, risk prediction, feature importance analysis, and an interactive Streamlit dashboard.

Technologies
Python | Pandas | NumPy | Scikit-learn | Random Forest | SMOTE | SciPy | Joblib | Streamlit
